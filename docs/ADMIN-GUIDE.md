# دليل استخدام لوحة الإدارة

لوحة الإدارة متاحة على الرابط: `https://موقعك/admin` (محليًا: `http://localhost:3000/admin`).
يمكن التبديل بين واجهة عربية وإنجليزية من زر اللغة أعلى اللوحة.

## 1. تسجيل الدخول والصلاحيات

- يُنشأ أول حساب مسؤول تلقائيًا من القيم `ADMIN_EMAIL` و`ADMIN_PASSWORD` في ملف `.env` عند تشغيل `npm run db:setup`.
- **غيّر كلمة المرور فور أول دخول** من: حسابي وكلمة المرور.
- الأدوار:
  - **مسؤول (ADMIN):** كل الصلاحيات، بما فيها الإعدادات والمستخدمون والمشتركون وسجل النشاطات والنسخ الاحتياطي وحذف الطلبات.
  - **محرر (EDITOR):** إدارة المحتوى والوسائط ومعالجة الطلبات.
  - **متدرب (LEARNER):** حساب في الموقع فقط (حفظ المواد المفضلة)، ولا يدخل اللوحة.
- تُسجَّل كل عملية (دخول، إضافة، تعديل، حذف، تصدير) في **سجل النشاطات**.

## 2. البدء: قائمة الإعداد

تعرض الصفحة الرئيسية للوحة **قائمة بالبيانات التي لم تُستكمل بعد**. أكملها بالترتيب:

1. **الإعدادات ← الصور والملفات:** ارفع صورتك الشخصية الحقيقية (يُفضل 4:5 بصيغة WebP أو JPG).
2. **الإعدادات ← بيانات التواصل:** البريد، الهاتف، واتساب (بالصيغة الدولية مثل `218912345678`)، لينكدإن، العنوان، وبريد استقبال الإشعارات.
3. **البرامج التدريبية:** أضف المدة وعدد الساعات لكل برنامج، وغيّر حالة التسجيل عند الجاهزية.
4. **مواعيد الدورات:** أضف المواعيد الفعلية.
5. **ملف السيرة الذاتية PDF** (اختياري).

## 3. البرامج التدريبية

- كل حقل نصي له خانتان: العربية والإنجليزية.
- الحقول التي تحتوي قوائم (الأهداف، الفئة المستهدفة، المحاور…): **عنصر واحد في كل سطر**.
- **حالة التسجيل:**
  - `OPEN` التسجيل مفتوح
  - `COMING_SOON` قريبًا – يمكن للزائر تسجيل اهتمامه
  - `ON_REQUEST` حسب الطلب للمؤسسات فقط (لا يظهر نموذج التسجيل الفردي)
  - `CLOSED` مغلق
- **مميز:** يظهر أولًا في الصفحة الرئيسية. **ترتيب العرض:** الرقم الأصغر يظهر أولًا.
- اترك "الرابط المختصر" فارغًا ليُنشأ تلقائيًا من العنوان الإنجليزي.

## 4. مواعيد الدورات

- اختر البرنامج، وتاريخ البداية والنهاية، والأيام والأوقات، ونمط التدريب (`IN_PERSON` حضوري / `ONLINE` عن بُعد / `HYBRID` مدمج)، والمكان.
- **المقاعد:** اتركها فارغة إذا لم تُعلن بعد. عند امتلاء المقاعد يمنع الموقع التسجيل تلقائيًا ويعرض "مكتمل".
- تظهر المواعيد تلقائيًا في صفحة البرنامج وجدول الدورات (قائمة وتقويم) ونموذج التسجيل.

## 5. الطلبات

أربعة صناديق: التسجيل، الاستشارات، التدريب المؤسسي، رسائل التواصل.

- يظهر عدد الطلبات الجديدة بجانب كل صندوق.
- افتح الطلب لرؤية التفاصيل، والتواصل عبر البريد أو الهاتف أو واتساب بضغطة، وتحميل مرفق الاحتياجات (للطلبات المؤسسية).
- حدّث **الحالة** وأضف **ملاحظات داخلية** لا يراها مقدم الطلب.
- **تصدير CSV:** يفتح مباشرة في Excel مع دعم العربية.

### الإشعارات
- كل طلب جديد يظهر في "أحدث الإشعارات" بلوحة التحكم.
- عند إعداد البريد (SMTP – راجع docs/OPERATIONS.md) يُرسل إشعار إلى بريد استقبال الإشعارات، وتصل المتدربَ رسالة تأكيد استلام.

## 6. المكتبة المعرفية

- **الأنواع:** مقال `ARTICLE`، نصيحة `TIP`، درس مرئي `VIDEO`، نموذج للتحميل `TEMPLATE`، اختبار قصير `QUIZ`.
- **المحتوى** يُكتب بصيغة Markdown:
  - `## عنوان فرعي`
  - `**نص عريض**`
  - `- عنصر قائمة`
  - `> اقتباس`
  - `[نص الرابط](https://...)`
- **الدروس المرئية:** الصق رابط YouTube أو Vimeo في حقل "رابط الفيديو".
- **النماذج:** ارفع الملف في حقل "ملف للتحميل".
- **الاختبار القصير:** اكتب الأسئلة في حقل JSON بالصيغة التالية:

```json
{
  "ar": [
    { "q": "نص السؤال؟", "options": ["الخيار أ", "الخيار ب", "الخيار ج"], "answer": 0, "explain": "شرح الإجابة الصحيحة" }
  ],
  "en": [
    { "q": "Question?", "options": ["Option A", "Option B", "Option C"], "answer": 0, "explain": "Why this is correct" }
  ]
}
```
`answer` هو رقم الخيار الصحيح بدءًا من 0.

- **تاريخ النشر:** يمكن جدولة النشر بتاريخ مستقبلي.

## 7. آراء المتدربين

لا يظهر الرأي في الموقع إلا إذا فُعّل خياران معًا: **"وافق المشارك على نشر رأيه"** و**"منشور"**. أضف آراء حقيقية فقط وبموافقة أصحابها.

## 8. الأرقام والمحطات

انشر الأرقام الموثقة فقط، ودوّن مصدر كل رقم في حقل "المصدر" (داخلي). يظهر القسم في الصفحة الرئيسية فقط عند وجود أرقام منشورة.

## 9. الشهادات والمؤهلات

يمكن إضافة صورة حقيقية للشهادة، ورقم الشهادة، ورابط التحقق. يظهر زر "التحقق عبر سجل شهادات PMI" للشهادات المهنية.

## 10. مكتبة الوسائط

ارفع الصور (JPG, PNG, WebP, AVIF, SVG حتى 8 ميغابايت) والملفات (PDF, Word, Excel, CSV, MP4 حتى 50 ميغابايت)، ثم انسخ الرابط لاستخدامه في أي حقل صورة أو داخل محتوى Markdown: `![وصف الصورة](/uploads/...)`.

## 11. المشتركون في النشرة البريدية

- التسجيل بتأكيد مزدوج: لا يُعد المشترك مؤكدًا إلا بعد ضغطه رابط التأكيد في بريده.
- صدّر القائمة CSV لاستخدامها في أداة إرسال النشرات (مثل Mailchimp أو Brevo). يتضمن الملف عمود `unsubscribe_url` لكل مشترك ليُضاف في رسائل النشرة.

## 12. الإعدادات

- **نصوص الصفحة الرئيسية:** اختيارية؛ عند تعبئتها تستبدل العنوان والنبذة الافتراضية (سطر لكل جملة في العنوان).
- **رسالة واتساب الجاهزة:** تُستخدم في الزر العائم، ويُضاف إليها اسم البرنامج تلقائيًا في صفحات البرامج.
- **سياسة الخصوصية:** يوجد نص افتراضي، ويمكن استبداله بنص مراجع قانونيًا.

## 13. النسخ الاحتياطي

من **النسخ الاحتياطي** حمّل نسخة JSON من قاعدة البيانات. للنسخ الدوري الكامل (قاعدة البيانات + الملفات) والاستعادة راجع `docs/OPERATIONS.md`.
