# نظام إدارة التدريب (LMS) — المرحلة الأولى: تحليل النظام الحالي وخطة التنفيذ

> التاريخ: 2026-11-27
> وفق الإيعاز التنفيذي المطوّر. **لم يُعدَّل في هذه المرحلة كود ولا قاعدة بيانات.**

## 1. الخلاصة

- أساس كبير من المطلوب **موجود ويعمل**: منصة الاختبارات كاملة (بنك لكل دورة، اختبارات، محاكاة، اختبار أخطاء، تحليلات، صلاحيات على مستوى قاعدة البيانات).
- **الناقص:** لوحة مدير على الإنترنت، إدارة المدربين والمتدربين، ملفات الدورات وفيديوهاتها، لوحة المتدرب الموحدة، الشهادات، الإشعارات، والأدوار المخصصة.
- **العائق الأساسي:** لوحة الإدارة الحالية تعمل على جهاز الكمبيوتر فقط، ولها حسابات منفصلة عن حسابات المنصة المنشورة.
- قبل البدء تلزم **خمسة قرارات** (القسم 6).

## 2. النظام الحالي

| العنصر | الوضع |
|---|---|
| التقنية | Next.js 15 وTypeScript وTailwind، وPrisma |
| قاعدة البيانات | PostgreSQL 17 على Supabase (حجمها الحالي 19 ميجابايت) |
| الموقع المنشور | ملفات ثابتة على GitHub Pages، تُبنى عند كل رفع ويوميًا |
| «الخادم» على الإنترنت | دوال PostgreSQL آمنة (`exam_*`) تتحقق من هوية المستخدم وصلاحيته |
| الدخول على الإنترنت | Supabase Auth، مربوط بجدول `ExamMember` |
| لوحة الإدارة `/admin` | **محلية فقط** (محتوى الموقع، الطلبات، الوسائط، النسخ الاحتياطي)، بجدول `User` منفصل |
| الملفات | خاصة للاختبارات (`exam-assets`: صور وPDF حتى 10 ميجابايت)، ومجلد محلي للوحة الإدارة |
| اللغات | العربية والإنجليزية مع RTL / LTR |

**البيانات الحالية** (تبقى كلها): 10 برامج، 208 أسئلة، اختباران، 3 محاولات، 3 تسجيلات في الدورات، عضوان، 50 مجلد اختبارات، طلب تسجيل واحد، 6 مواد معرفية.

## 4. ما سيُعاد استخدامه

- جداول `Program` و`ExamMember` و`CourseInstructor` و`Enrollment` (تُوسَّع ولا تُستبدل).
- منصة الاختبارات كما هي، **دون منصة جديدة**.
- قارئ Excel وCSV (لاستيراد المتدربين)، وكاتب Excel (للتقارير).
- سجل التدقيق، ومخطط الرسوم والجداول، والقاموسان، والهوية البصرية.

## 5. قيود يجب معرفتها

أرقام Supabase من صفحة الأسعار الرسمية بتاريخ اليوم.

| القيد | الخطة المجانية | Pro (من 25 دولارًا شهريًا) |
|---|---|---|
| تخزين الملفات | 1 جيجابايت | 100 جيجابايت |
| أكبر ملف | 50 ميجابايت | قابل للرفع كثيرًا |
| حجم قاعدة البيانات | 500 ميجابايت | 8 جيجابايت |
| التنزيل الشهري | 5 جيجابايت | 250 جيجابايت |
| النسخ الاحتياطي التلقائي | **لا يوجد** | يومي، 7 أيام |
| الإيقاف | **يتوقف المشروع بعد أسبوع بلا نشاط** | لا يتوقف |
| البريد المدمج | رسالتان في الساعة (يلزم بريد SMTP خاص) | نفس الحد دون SMTP خاص |

**GitHub Pages:** شروطه تنص على أنه غير مخصص ولا مسموح به لاستضافة عمل تجاري إلكتروني أو خدمة برمجية تجارية، ولا للمعاملات الحساسة مثل إرسال كلمات المرور ([المصدر](https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits)). كلمات المرور تُرسل إلى Supabase لا إلى GitHub، لكن **منصة تدريب لشركة تقع على الأرجح ضمن الاستخدام التجاري**. أنصح بنقل الواجهة إلى استضافة تسمح بذلك قبل فتح المنصة للمتدربين. الموقع ملفات ثابتة فالنقل بسيط، وسأتحقق من شروط البديل قبل اقتراحه نهائيًا.

**حدود لا يمكن ضمانها:**
- منع تنزيل الفيديو أو تصوير الشاشة بنسبة 100% غير ممكن في المتصفح.
- رابط YouTube «غير المدرج» يمكن لمن يحصل عليه مشاركته.
- المدير لا يرى كلمات المرور، وإعادة التعيين تكون برابط أو كلمة مؤقتة.
- «حذف الحساب» مع الاحتفاظ بالنتائج يعني تعطيله وإخفاء بياناته الشخصية.
- لا يتوفر فحص فيروسات للملفات المرفوعة، بل تحقق من النوع والحجم.

## 6. القرارات المطلوبة منكم

| # | القرار | توصيتي |
|---|---|---|
| 1 | أين تعمل لوحتا المدير والمتدرب؟ | **على البنية الحالية** (صفحات ثابتة + Supabase). العمليات التي تحتاج صلاحيات عليا (إنشاء حساب، إعادة كلمة المرور، البريد) تنفَّذ بدوال Supabase الخادمية (500 ألف استدعاء مجانًا). البديل خادم مدفوع وإعادة ربط المنصة |
| 2 | استضافة الواجهة | نقلها من GitHub Pages قبل الإطلاق للمتدربين |
| 3 | الفيديوهات | **روابط YouTube غير مدرجة** (دون تكلفة). رفع الفيديو إلى المنصة يحتاج خطة مدفوعة |
| 4 | الخطة | البدء **مجانًا** للتطوير، والانتقال إلى Pro قبل التشغيل الفعلي (نسخ احتياطي ولا إيقاف) |
| 5 | البريد | تزويدي بإعدادات SMTP لبريد الشركة. **لا ترسلوا كلمة المرور في المحادثة**، بل تُدخل مباشرة في إعدادات Supabase |

## 7. خطة التنفيذ

كل مرحلة تنتهي باختبارات حقيقية وتقرير ونشر، ولا تبدأ التالية قبل موافقتكم.

| المرحلة | المحتوى | شرط القبول |
|---|---|---|
| **LMS-1** الأساس | نسخة احتياطية كاملة مع تجربة استعادتها، الأدوار والصلاحيات (Super Admin وأدوار مخصصة)، سجل العمليات، هيكل لوحة المدير (قائمة جانبية وشريط علوي) | لا يصل أحد لوظيفة دون صلاحية، والبيانات الحالية سليمة |
| **LMS-2** المستخدمون | المدربون، المتدربون (إضافة واستيراد)، التسجيل ومدة الصلاحية والتعليق، إعادة كلمة المرور | إنشاء متدرب ودخوله فعليًا |
| **LMS-3** المحتوى | الأقسام الثلاثة لكل دورة، مكتبة الملفات، مكتبة الفيديو، تتبع التقدم | متدرب دورة لا يرى ملفات غيرها |
| **LMS-4** دمج الاختبارات | ربطها بصفحة الدورة، إتاحة الاختبار لمتدربين محددين، عرض نقاط القوة والضعف | لا تكرار لأي وظيفة قائمة |
| **LMS-5** المتدرب | لوحة المتدرب، الملف الشخصي، الشهادات PDF ورابط التحقق، مؤشر الاستعداد | شهادة يتحقق منها طرف خارجي |
| **LMS-6** الإدارة | الصفحة الرئيسية للمدير، مركز التقارير، الإشعارات، الإعدادات | أرقام مطابقة لقاعدة البيانات |
| **LMS-7** الإطلاق | مراجعة أمنية، اختبار كل دور وكل جهاز (تشمل المرحلة 13 المتبقية للاختبارات)، التوثيق | معايير القبول في الإيعاز كلها |

اختيارية بعد ذلك: المسار التعليمي، وحضور المتدربين.

**نقل محتوى الموقع** (البرامج والمواد والطلبات) من اللوحة المحلية إلى اللوحة الجديدة يتم تدريجيًا ضمن LMS-6، وتبقى المحلية تعمل حتى ذلك.
